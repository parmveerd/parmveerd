## 🛠️ Featured Projects

Here are a few things I've worked on:

* **AskMyDocs** – Production-ready RAG API that answers questions strictly from provided documents, returning grounded responses with source citations and no hallucinated information
* **AI Inference Queue** – Distributed AI inference job queue with priority scheduling, async worker pools, rate limiting, retries, dead letter queues, and webhook-based result delivery
* **DSA Vault** – Terminal-based offline tool for practicing DSA problems with multi-language support, progress tracking, timers, and fully local storage for distraction-free coding
* **LLM Evaluator** – LLM evaluation framework that scores outputs for correctness, relevance, and hallucinations, tracks regressions over time, and provides both API and CLI access for systematic testing
* **MarketPulse** – Real-time financial data pipeline fetching stock and crypto prices, streaming via Redis, aggregating OHLCV bars in PostgreSQL, exposing alerts, metrics, and a FastAPI + frontend dashboard for real-time monitoring
* **Personal Dashboard** – Fully local personal dashboard for finance, health, habits, journaling, weather, and stocks, with zero cloud storage and full offline capability
